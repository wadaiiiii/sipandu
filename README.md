# SiPANDU

**SiPANDU — LMS Berbasis OBE** untuk Program Studi S1 Matematika FMIPA Universitas Sulawesi Barat.

SiPANDU dirancang sebagai LMS yang mandiri secara operasional. Integrasi dengan SiMatRPS bersifat opsional melalui lapisan sumber RPS sehingga SiPANDU tetap dapat digunakan bila sumber RPS berubah menjadi input manual, import file, atau sistem fakultas/eksternal.
